# ARCHITECTURE.md  
LuckyAISystems — Architecture (v3.0)

## 1. Purpose
This document shows the structural layout of LuckyAISystems.  
It explains how the Direction, Governance, and Execution layers fit together and provides Guided Links to each subsystem.

LuckyAISystems is a **layered knowledge system**, not a collection of folders.  
This page is the navigation map.

---

## 2. System Layers

LuckyAISystems is organized into three major layers:

### **A. Direction Layer**  
Governs identity, priority, architecture, and long‑term capability.

- [Operation Capability](ca://s?q=Open_Operation_Capability)  
- [NEXT_DECISION](ca://s?q=Open_NEXT_DECISION)

### **B. Governance Layer**  
Governs how knowledge is produced, refined, verified, and preserved.

- [Communication OS](ca://s?q=Open_Communication_OS)  
- [Verification Layer](ca://s?q=Open_Verification_Layer)  
- [Knowledge Production Pipeline](ca://s?q=Open_Knowledge_Production_Pipeline)

Contains real engineering work, observations, systems, and applied knowledge.
