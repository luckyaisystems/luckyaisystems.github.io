# Site Notes Compiler — Incidents Index

**Purpose:** Capture and categorize operational incidents to build case studies, SOPs, and promotion evidence.

---

## What Counts as an Incident?

Any event that requires:

- Operator intervention
- Troubleshooting
- Escalation
- Reset
- Monitoring
- Documentation

Examples:

- Alarms
- Resets
- Environmental deviations
- Equipment faults
- Unexpected behavior
- Safety events

---

## How To Use This Folder

1. After each shift, identify incident-level events
2. Create a new `.md` file using **site-note-template.md**
3. Categorize the incident:
   - Alarm
   - Reset
   - Failure
   - Deviation
   - Safety
4. Link the incident to:
   - Systems
   - Patterns
   - Weekly compilations
   - DHRs
