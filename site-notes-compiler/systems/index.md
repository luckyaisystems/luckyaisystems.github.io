# Site Notes Compiler — Systems Index

**Purpose:** Organize internship notes by critical facility system for structured learning and rapid retrieval.

---

## Why Systems Matter

Critical Facilities work is system-driven. Every observation eventually maps to one of the following:

| System | Function |
|--------|----------|
| **UPS** | Power continuity |
| **BMS** | Environmental control |
| **CRAH / HVAC** | Cooling stability |
| **Fire Systems** | Life safety |
| **Security** | Access control |
| **Generators** | Backup power |
| **Switchgear** | Electrical distribution |

This folder groups notes by system so patterns can emerge faster.

---

## How To Use This Folder

1. After each shift, identify which system your note belongs to
2. Create a new `.md` file inside the correct system folder
3. Use **site-note-template.md**
4. Link the note to:
   - Patterns
   - Incidents
   - Weekly compilations
   - DHRs
