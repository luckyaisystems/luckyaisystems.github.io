# Site Notes Compiler — Patterns Index  
**Purpose:** Extract recurring operational patterns from internship notes and convert them into reusable knowledge.

---

## What This Folder Represents
Patterns are the *first layer of intelligence* produced by the Site Notes Compiler.  
They reveal:

- repeated system behaviors  
- recurring failure modes  
- common alarm sequences  
- environmental correlations  
- operator actions that consistently work  
- operator actions that consistently fail  

Patterns become the backbone for:

- case studies  
- SOPs  
- DHRs  
- promotion evidence  
- CFT‑IV readiness signals  

---

## How Patterns Are Created
1. Capture raw notes in the physical journal  
2. Transfer notable entries into **site-note-template.md**  
3. Run the **pattern-extraction-template.md**  
4. Store the extracted pattern here  
5. Link patterns to:
   - systems  
   - incidents  
   - weekly compilations  
   - DHRs
