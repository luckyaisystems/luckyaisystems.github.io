## Document Category Separation <a name="categories"></a>

The repository maintains a strict separation between three document types:

| Category | Definition | Examples |
|----------|-----------|----------|
| **Evidence** | Things that actually happened | reflection.md, case studies, DHRs |
| **Interpretation** | What evidence means | Design History Records, architectural doctrines |
| **Planning** | Where the system goes next | Blind Spot Pre-Mortem, NEXT_DECISION, CFT-IV Rubric |

This separation increases credibility and prevents aspiration from masquerading as fact.

## The Workflow Over Prompt Principle <a name="workflow-over-prompt"></a>

The TikTok workflow catalyzed the architecture but is not its foundation.

| Layer | Durability |
|------|-----------|
| A prompt | Ephemeral -- disappears when the session ends |
| A workflow | Durable -- survives as long as the process is followed |
| An architecture | Self-sustaining -- survives even if workflows change |

The original TikTok prompt could disappear tomorrow. The repository would still contain:

- The doctrine that defines how knowledge enters
- The pipeline that defines how knowledge transforms
- The verification layer that constrains trust
- The design history that records why decisions were made
- The operational framework that connects theory to practice

That is the difference between using AI and architecting AI output.

## Unfreeze Conditions <a name="unfreeze"></a>

The architecture may be unfrozen only when one of the following occurs:

| Condition | Rationale |
|-----------|-----------|
| Operational evidence reveals a structural gap | The architecture failed to accommodate a real scenario |
| A new domain requires integration the current layers cannot support | Expansion beyond Equinix/Seneca scope |
| Multiple operational case studies expose a recurring classification problem | Categories need redefinition |
| The CFT-IV rubric reveals capability gaps the architecture cannot address | Career progression requires new structures |

Until one of these conditions is met, the architecture is frozen.

New evidence feeds the existing structure. The structure does not expand.
