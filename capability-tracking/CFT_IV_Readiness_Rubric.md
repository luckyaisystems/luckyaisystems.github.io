# CFT‑IV Readiness Rubric  
LuckyAISystems — Capability Tracking

## 1. Purpose
This rubric defines the competency progression from Technician I → CFT‑IV.  
It guides internship evidence collection, Seneca coursework alignment, and long‑term capability development.

Use this page to:
- Identify current skill gaps  
- Plan evidence collection  
- Map internship tasks to long‑term capability  
- Track progression toward CFT‑IV readiness  

---

## 2. Competency Matrix

| Domain | Technician I | Technician II | Technician III | CFT‑IV (Target) |
|--------|--------------|---------------|----------------|-----------------|
| **UPS Systems** | Monitor alarms, basic troubleshooting | Replace batteries, run load tests | Full UPS maintenance, firmware updates | Lead RCA on UPS failures, train juniors |
| **Generators** | Start-up procedures, fuel checks | Routine maintenance, oil changes | Full service coordination, testing protocols | Vendor management, compliance audits |
| **BMS Monitoring** | Alarm response, ticket logging | Filter adjustments, sensor calibration | System configuration, trend analysis | Author SOPs for BMS procedures |
| **HVAC/Chillers** | Room temp checks, filter replacement | CRAC maintenance, coolant checks | Chiller optimization, water treatment | Energy efficiency projects, capacity planning |
| **MOP/SOP Writing** | Follow documented procedures | Minor updates | Write MOPs for standard tasks | Author SOPs, lead procedural reviews |
| **Incident Command** | Escalate per protocol | Lead minor incidents, document timeline | Major incident commander, RCA | Multi-system failures, executive comms |
| **Vendor Coordination** | Witness vendor work | Review vendor MOPs, QA | Lead vendor projects, approve work orders | Contract oversight, SLA management |
| **Shift Independence** | Supervisor presence required | Minimal supervision | Independent work, mentor juniors | Cross-shift coverage, decision authority |
| **Experience Required** | 0–1 year | 1–2 years | 2–3 years | 3+ years (target: ~2.5 with Seneca + internship) |

## 4. Evidence Collection Strategy

### A. Internship (Sept–Nov 2026)
- Capture **incident timelines**  
- Document **UPS/BMS/HVAC observations**  
- Shadow senior technicians  
- Request exposure to vendor work  
- Build **case studies** using Pipeline v3  

### B. Seneca Coursework (2026–2028)
- Map each course to a domain in the matrix  
- Convert labs → artifacts  
- Convert failures → RCA templates  
- Convert projects → capability evidence  

### C. GitHub Portfolio
- Store all artifacts under `/capability-tracking/`  
- Maintain version-controlled progression  
- Link artifacts to rubric domains
